## Adjuntar archivos locales a cards de Trello

Nueva capacidad: subir ficheros locales como adjuntos de una card vía la API de Trello (`POST /1/cards/{id}/attachments`, multipart/form-data). Sigue el patrón del repo: Node nativo sin dependencias, un script CLI por operación, `resolveCard` para localizar la card.

### 1. `scripts/trello/lib.mjs` — nuevo helper `attachFile(cardId, filePath, name?)`
- Imports añadidos: `basename` de `node:path`, `statSync`/`existsSync` de `node:fs`.
- `attachFile(cardId, filePath, name)`:
  - Valida que el fichero exista y que pese ≤ 10 MB (límite de adjuntos de la API de Trello) → error claro si no.
  - Construye `FormData` nativo (Node ≥ 20) con el campo `file` (Blob del contenido) y nombre por defecto = basename, salvo `--name`.
  - `fetch` directo a `https://api.trello.com/1/cards/{id}/attachments?key=…&token=…` **sin** fijar `Content-Type` manualmente (fetch pone el boundary multipart solo). Reutiliza el bucle de retry 429 y el formato de error de `api()` (mismo patrón que `lib.mjs:58-89`).
  - Devuelve el JSON de Trello (id, url, name del adjunto).

### 2. `scripts/trello/attach-file.mjs` — nuevo script CLI
Sigue la plantilla de `update-card.mjs` (shebang + JSDoc con `Uso:`, `getArg` manual, exit codes 0/1, salida con emojis):
```
node scripts/trello/attach-file.mjs --card "Título|#92|shortId" --file ./captura.png[,./otro.pdf] [--name "Nombre opcional"]
```
- `--card` obligatorio → `resolveCard` (falla con listado de lo probado si no existe).
- `--file` obligatorio → lista separada por comas (mismo idioma que `--label-add`); valida existencia y tamaño de cada uno.
- `--name` opcional: override del nombre del adjunto (aplica a todos los ficheros).
- Salida: `📎 Adjunto subido: <nombre> (<KB>)` + URL del adjunto por fichero.
