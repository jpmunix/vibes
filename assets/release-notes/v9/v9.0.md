# v9.0

_2 de julio de 2026_

## Migración a infraestructura Bunny

Hemos migrado todo el sistema de almacenamiento subyacente a una nueva infraestructura basada en Bunny. Este cambio arquitectónico profundo mejora drásticamente la fiabilidad y el rendimiento en el manejo de archivos y adjuntos.

## Soporte para herramientas de visión y preprocesador universal

Hemos habilitado el soporte completo para herramientas de visión (Vision Tools) en el entorno. Además, para maximizar la compatibilidad, hemos implementado un preprocesador de visión inteligente a nivel de IA. Ahora, incluso los modelos que no cuentan con capacidades de visión de forma nativa podrán procesar flujos de trabajo visuales, ya que el preprocesador se encarga de analizar y extraer el contexto de las imágenes antes de pasarlas al modelo.

## Notificaciones nativas para permisos

Cuando el agente requiere aprobación para ejecutar comandos o realizar operaciones que necesitan permisos especiales, ya no tendrás que estar mirando la ventana del chat. El sistema ahora se integra con tu sistema operativo para lanzar notificaciones nativas de escritorio, avisándote de inmediato de que hay una solicitud pendiente de revisión.

## Mejoras en el contexto de las interacciones

Hemos ajustado el sistema de comunicación IPC para que las respuestas del usuario incluyan automáticamente el contexto de la pregunta original. Esto mejora significativamente la coherencia del agente a la hora de procesar aprobaciones, aclaraciones y selecciones múltiples, ya que siempre tiene presente a qué estaba respondiendo exactamente el usuario.
